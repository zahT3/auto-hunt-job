如何登录独立浏览器

在项目目录的终端中，按渠道运行：

python -m hunt.sources_browser --login boss --data private/apppython -m hunt.sources_browser --login liepin --data private/app

使用自定义数据目录时，将 private/app 换为启动工作台时的同一 --data 路径。选择 Google Chrome 时附加 --browser chrome；两种浏览器不共享登录。完成本人登录后回到终端按回车，再运行搜索。遇到验证会停止该渠道。
