# 开发预览版验收记录

验收日期：2026-10-22 至 2026-10-23。本地 macOS，全部候选人资料为合成样例。真实投递、消息发送与招聘站简历上传均为 0。

## 已验证

- 网页上传合成 PDF 和 DOCX，各提取 12 项事实；人工勾选后激活。事实仍为私密，不自动变成申请披露授权。
- 本地画像展示技能提及及事实来源；岗位提供关联技能、未提及项和硬条件待确认结果。
- 界面触发真实后台扫描，6 个渠道共保留 20 个岗位，生成 20 份本地准备记录，可执行申请为 0。状态如实显示部分完成。
- 本轮来源分布：安克 3、Greenhouse/Anthropic 6、Lever/Binance 6、Ashby/Cursor 5。请求和结果数受预算约束，不是全量岗位。
- BOSS 公开请求受阻；独立浏览器未登录时跳转登录页。右侧浏览器随后显示 IP 异常访问安全验证，尚未验收登录后的稳定采集。
- 猎聘独立浏览器曾读取列表和一个完整详情，后续出现非岗位页面跳转；界面轮次受阻，不能据一次成功宣称稳定接入。
- 简历原件、浏览器资料、原始岗位响应、截图与数据库均保留在本地，未纳入发布白名单。

## 回归检查

使用 `python -m unittest discover -s tests -v`、`node --check static/app.js` 与 `node --test tests/test_frontend.cjs`。检查覆盖本地上传、来源映射、合成资料禁止申请、失效批准、并发控制、恢复、来源失败与空结果区分、预算、请求约束及前端状态。具体通过数量以该提交的 CI 记录为准。

本机实际浏览器已完成 PDF/DOCX 上传、确认、目标保存、后台搜索及结果展示。页面已检查窄窗口布局。

## 尚未通过的验收

- BOSS/猎聘登录后的连续可靠采集。
- 任意扫描简历的 OCR、复杂文档的完整理解；当前画像使用本地规则。
- 未配置公司与整个互联网的覆盖率。SearXNG 接口有夹具验证，尚无真实配置验收。
- 真实招聘站提交、发送消息及回执。其他来源只有只读接入；安克执行器的本地模拟测试不代表线上投递通过。

此版本适合验证“上传—核对—多渠道搜索—查看依据—集中审核”的本地流程，不能承诺全自动求职闭环。
