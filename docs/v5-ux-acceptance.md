# v5：四步流程审查

2026-10-23，使用 Product Design 审查现有工作台。验收数据独立，候选人、DOCX 和岗位都是合成示例；本轮不连接招聘站、不投递。

## 问题与修复目标

1. 上传失败后在同一弹窗重试，旧错误可能与新事实并存；应清理错误，并把解析中的反馈放在上传按钮上。
2. 事实来源直接展示长文件 hash，影响阅读；应优先展示页码或段落，完整来源保留在展开项中。解析成功后焦点移到结果标题。
3. 编辑目标后，主按钮没有提示未保存，而且会使用旧条件；应先验证并保存，再开始搜索。保存失败不能启动搜索，演示模式始终使用本地示例。
4. “审核材料”进入对外授权界面，未支持执行的渠道无法完成本地复核；应新增独立的本地复核记录，并保留待补信息。

本地复核只记录已查看当前材料，不批准填写、上传或提交，不更改披露权限。记录绑定候选资料、目标、岗位、材料和文件的快照；任一内容改变，旧复核标记失效。对外批准仍走原有独立权限与快照核验。
